# 위시 · 링크 페이지

어둡고 세련된 분위기의, 나만의 링크 모음 페이지입니다.
휴대폰에서 먼저 보기 좋게 만들었고, 컴퓨터 화면에서도 예쁘게 보입니다.

**모든 내용은 `config.js` 파일 하나에서 바꿉니다.** 나머지 파일은 건드리지 않아도 됩니다.

---

## 1. 먼저 미리 보기

저장소를 내 컴퓨터로 내려받았다면 `index.html` 파일을 두 번 눌러 브라우저로 열면 바로 보입니다. (인터넷 없이도 열립니다.)

---

## 2. 내용 바꾸기 — `config.js`

GitHub에서 바꾸는 방법:

1. 이 저장소 페이지에서 **`config.js`** 파일을 누릅니다.
2. 오른쪽 위 **연필 모양(✏️, Edit this file)** 을 누릅니다.
3. 아래 내용을 고칩니다.
4. 화면 아래 **Commit changes** 버튼을 누르면 저장(적용)됩니다.

### 이름과 소개

```js
name: "위시",
bio: "모든 사람들에게 친절을 베풀어 주고 싶어요!",
```

### 프로필 사진 (선택)

지금은 이름의 첫 글자(`위`)로 동그란 프로필이 만들어집니다.
사진을 넣고 싶다면:

1. 저장소 첫 화면에서 **Add file → Upload files** 로 사진을 올립니다. (예: `profile.jpg`)
2. `config.js` 에서 파일 이름을 적습니다.

```js
avatar: "profile.jpg",
```

### 링크 추가하기

`links: [ ... ]` 안에 한 줄씩 넣습니다. 이미 GitHub 링크 하나가 들어 있고, 인스타그램·유튜브·블로그·X 예시는 `//` 로 막아 두었습니다.
**쓰고 싶은 예시의 앞에 있는 `//` 를 지우고, 주소만 내 것으로 바꾸면** 바로 나타납니다.

```js
{
  label: "인스타그램",                          // 버튼에 보이는 이름
  url: "https://instagram.com/내아이디",         // 주소
  description: "일상 기록",                      // (선택) 버튼 아래 작은 설명
  icon: "instagram",                            // (선택) github / instagram / youtube / x / blog / link
},
```

- 새 링크를 직접 추가할 때는 **앞 항목과의 사이에 쉼표(`,`)** 를 꼭 넣으세요.
- `icon` 을 안 적으면 사슬 모양 아이콘이 나옵니다.
- `https://` 를 빼고 `instagram.com/아이디` 처럼 적어도 자동으로 붙습니다.

### 분위기(색) 바꾸기

```js
theme: {
  accent: "#a08cff",   // 대표 색
  accent2: "#5ad1ff",  // 두 번째 색
},
```

색은 `#` 으로 시작하는 색상 코드를 쓰면 됩니다.

### 맨 아래 문구

```js
footer: "© 위시",
```

## 3. 주의할 점

- **이메일, 전화번호, 집 주소 같은 개인정보는 넣지 마세요.** 링크 페이지는 공개되면 누구나 볼 수 있습니다.
- `config.js` 에서 **큰따옴표(`"`)** 와 **쉼표(`,`)** 를 지우면 페이지가 하얗게 나옵니다. 오타가 났을 때는 마지막으로 고친 부분부터 확인하세요.

---

## 4. 인터넷에 공개하기 (원할 때만)

지금 이 저장소는 **비공개(Private)** 라서 나만 볼 수 있습니다. 주소를 다른 사람에게 알려주려면 공개로 바꾸고 GitHub Pages를 켜야 합니다.

1. 저장소 **Settings → General** 맨 아래 **Danger Zone → Change repository visibility → Make public**.
   - GitHub 무료 플랜에서는 **비공개 저장소로는 Pages를 쓸 수 없습니다.** 공개로 바꿔야 합니다.
2. **Settings → Pages** 에서 *Source* 를 **Deploy from a branch**, 브랜치를 **main**, 폴더를 **/(root)** 로 두고 **Save**.
3. 1~2분 뒤 `https://moonjin1.github.io/` 에서 페이지가 열립니다.

> 공개로 바꾸면 이 저장소의 파일(사진 포함)을 누구나 볼 수 있습니다. 올리기 전에 개인정보가 없는지 한 번 더 확인하세요.
